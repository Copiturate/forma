## Что покрывают Java-тесты

- Формулы расчёта, оба предела площади, все направления, неверный ввод.
- Валидация email/имени/площади/сообщения/согласия, неизвестные поля и повреждённый JSON.
- Работа миграции и JPA с реальной H2, создание и повтор заявки.
- Два конкурентных запроса с одинаковым UUID оставляют ровно одну строку.
- Конфликт UUID с другим содержимым, переходы статусов и ожидаемая версия.
- Авторизация и роль, обязательный CSRF, реальный вход настроенной учётной записью.
- Фильтрация, страницы по 12 записей, некорректная страница, отсутствующая заявка.
- HTTP 405/415, ограничение тела 16 КиБ, окно ограничителя частоты.

Конкурентный тест намеренно вызывает уникальное ограничение базы в одном из потоков. Сообщение Hibernate об этом в журнале ожидаемо: исключение обработано, обе операции получают одну квитанцию, тест проходит. Предупреждение Mockito о динамической загрузке агента на JDK 21 не является падением тестов.

## Какие проблемы нашлись во время проверки

1. Неправильный формат BCrypt-хеша для DelegatingPasswordEncoder — добавлен префикс `{bcrypt}`.
2. Различие между перенаправлением страницы кабинета и ответом API — страницы получают login redirect, admin API получает `401`.
3. Переполнение блока этапов на планшете — исправлены ширины grid и расположение текста.
4. Последний commit мог потеряться при немедленном завершении процесса из-за отложенной записи H2 — добавлен `WRITE_DELAY=0`, повторный тест перезапуска прошёл.
5. На Windows нельзя пересобирать запущенный JAR из-за блокировки файла. Перед финальной сборкой тестовый сервер остановлен; пересборка и последующий запуск прошли.

## Пределы проверки

- **Docker / Compose не запускались:** Docker отсутствует в среде.
- **GitHub Actions не запускался на GitHub:** workflow создан, его команды проверялись локально; репозиторий не опубликован.
- macOS / Linux, HTTPS reverse proxy, несколько экземпляров сервиса и реальная нагрузка не проверялись.
- npm audit относится только к Node dev-зависимостям. Отдельный CVE-скан Java-зависимостей и формальный pentest не выполнялись.
- Тест перезапуска подтверждает сценарий остановки процесса в этой среде; отключение питания или отказ диска не имитировались.
- Отправки email, внешних интеграций и PostgreSQL в реализации нет, их работоспособность не заявляется.
